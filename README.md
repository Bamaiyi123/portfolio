# Adeyi Bamaiyi — AI Engineer Portfolio

This is a simple, responsive portfolio website for Adeyi Bamaiyi showcasing AI / ML skills, projects, and contact details.

## Files

- `index.html` — Main website page (About, Skills, Projects, Contact)
- `styles.css` — Styling and responsive rules
- `script.js` — Small interactive scripts (menu, smooth scroll, form behavior)
- `profile-photo.jpg` — Your profile image used in the About section

## Quick start

1. Open the site locally by double-clicking `index.html` or open it in your browser:

   ```bash
   # from terminal (optional)
   start index.html
   ```

2. The site is static — no build step or server required for local preview.

## Customize

- Replace the placeholder text in `index.html` with your own bio, experience, and project descriptions.
- To change your photo, replace `profile-photo.jpg` in the project folder. The image is displayed in the About section.
- Update project links in the Projects section (`index.html`) to point to your GitHub repositories or live demos.
- Update contact details (email, phone, location, social links) in the Contact section of `index.html`.

## Deployment

You can host this site for free. Two quick options:

- GitHub Pages
  1. Initialize a git repo in the folder and push to GitHub.
  2. In the repository Settings → Pages, set the branch to `main` (or `gh-pages`) and root to `/`.
  3. Your site will be available at `https://<your-username>.github.io/<repo>`.

- Netlify / Vercel
  1. Drag-and-drop the project folder into Netlify, or connect the GitHub repo to Netlify/Vercel.
  2. Both services will host the static site automatically.

## Notes & Tips

- Images: use a reasonably sized JPG/PNG (prefer < 1MB); the layout uses `object-fit: cover` so portrait crops nicely.
- Accessibility: add descriptive `alt` text to images and meaningful link labels for better accessibility.
- Add a `robots.txt` or `sitemap.xml` later if you deploy and want search engines to index your site.
